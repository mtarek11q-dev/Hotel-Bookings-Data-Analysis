# 📊 Hotel Bookings: End-to-End Data Analysis & Prediction

## 📌 Project Overview
This project delivers a comprehensive business intelligence and predictive analysis of hotel booking data. The goal is to analyze customer booking patterns, identify cancellation factors, build interactive performance dashboards, and develop machine learning models to forecast booking cancellations.
